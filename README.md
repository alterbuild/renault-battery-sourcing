# Sourcing the battery

A strategic sourcing plan for Renault Group's LFP cell-to-pack batteries, presented as a web slide deck.

**Open the deck:** https://alterbuild.github.io/renault-battery-sourcing/

Group case study for Purchasing and Supply Chain, EDHEC International BBA (Lille, November 2026), by Diego Martínez, Juan Tent, Leyla Marco, Mathias Steffanson and Lukas.

## Using the deck

- Arrow keys or Space: next and previous slide
- N: speaker notes
- P: presenter view in a second window (notes, timer, next slide)
- F: full screen
- I: info

The deck is a single self-contained HTML file (`index.html`): fonts, photos and logos are embedded, so it also works offline.
